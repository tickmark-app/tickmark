# Security policy

Tickmark can read your screen, so we take security reports seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/tickmark-app/tickmark/security/advisories/new).

We aim to acknowledge a report within 7 days. We fix confirmed issues before
disclosing them and credit reporters in the release notes unless they prefer
otherwise.

## Supported versions

Tickmark is pre-alpha. Only the latest release receives fixes.

## What Tickmark does with your data

- No telemetry, no accounts.
- Screen content never leaves your computer.
- The only network request is the optional, opt-in update check against
  GitHub Releases.
